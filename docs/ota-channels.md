# Phantom VPN: стабильный и бета-канал в одном приложении

Решение владельца от 23.11.2026. **Один** Android-пакет `xyz.wraithnet.phantom`, **один** универсальный APK с ARM64/ARM32/x86/x86_64 и **один** официальный ключ подписи для обоих каналов. Никаких отдельных Beta-приложений и удаления пользовательских данных.

## Пользовательский интерфейс

«Настройки → О приложении → Получать бета-обновления» (телефон/Android TV). По умолчанию `OFF`, значение хранится в `phantom_preferences/beta_apk_updates`. Изменение инициирует немедленную повторную OTA-проверку, сбрасывает предыдущий список доступных обновлений и отменяет незавершённую загрузку предыдущего канала.

- **OFF**: искать только обычные стабильные GitHub Releases без `draft` и `prerelease`.
- **ON**: искать обычные стабильные GitHub Releases и prerelease со строго заданным тегом `vX.Y.Z-beta.N` (`N >= 1`). Отбрасывать любые неизвестные форматы.
- При включении беты показывать самую новую совместимую версию среди двух каналов; явно помечать предложение «Бета-версия».
- Проверять SHA-256 актива, `packageName`, идентичную подпись и `versionCode > installedVersionCode` перед установкой через Android PackageInstaller. Без принудительного downgrade.

## Как выпускать

Используй `.github/workflows/quick-apk.yml` → Run workflow на `main`, `source_sha` пустой, `publish_release=true`.

- `release_channel=stable`: `versionName=X.Y.Z`; GitHub Release обычный, `--latest`, файл `phantom-universal-release.apk`; сайт `app.veor.pro` и постоянная ссылка ведут сюда.
- `release_channel=beta`: `versionName=X.Y.Z-beta.N`; GitHub Release помечается **prerelease** с `--latest=false`, тот же файл `phantom-universal-release.apk` и официальный сертификат. Главная кнопка сайта и `releases/latest` остаются на последней стабильной версии.
- При выпуске любой версии `versionCode` должен быть больше **последнего стабильного И последнего бета-релиза**. GitHub workflow проверяет это до публикации.
- Например: `0.3.24` (51, stable) → `0.3.25-beta.1` (52, beta) → `0.3.25-beta.2` (53, beta) → `0.3.25` (54, stable). Это разные релизы одного приложения и одного сертификата, **не разные APK-пакеты**.

## Почему выключение переключателя не откатывает установленную бету

Android запрещает установку меньшего `versionCode` поверх большего. Если стоит `0.3.25-beta.1` (52), а последняя stable `0.3.24` (51), после выключения переключателя приложение продолжает работать как есть. Следующий стабильный релиз (`0.3.25`, 54) установится поверх него без потери настроек. Сбрасывать данные или удалять приложение для переключения каналов **нельзя**.

## Проверки

Для обычных изменений — QUICK: адресные unit/UI-тесты, Gradle, подпись, файл и OTA. Для изменений обновлятора/сертификата не пропускать критические адресные проверки. Полная Android+TV матрица по отдельной просьбе владельца, согласно [docs/release-fast.md](release-fast.md).
