# Макеты SmartVoiceKeyboard

Эти файлы — **визуальные черновики**, а не готовая Android-клавиатура.

- Полное ТЗ: [UI_DESIGN_SPEC_v1.md](../UI_DESIGN_SPEC_v1.md)
- Генератор 15 индивидуальных PNG и 5 обзорных панелей: `../../scripts/generate_ui_mockups.py`
- Команда в отдельной рабочей копии репозитория с установленным Pillow: `python3 scripts/generate_ui_mockups.py`
- Результат: `docs/mockups/*.png` и `docs/mockups/SmartVoiceKeyboard_UI_mockups_v1.zip`
- Ручной запуск только по отдельному поручению владельца. Не запускать автоматические сборки, Actions и APK.

Основные состояния: обычная клавиатура, компактная карточка буфера, жестовый набор, меню по четырём точкам, полный буфер, голосовой ввод, изменение размера, главные настройки, раскладка, ввод и жесты, голос, буфер, темы, приватность и светлый вариант.

**Важно:** в исходном коде генератора изображения отображают пример общения лишь как фон стороннего приложения. Собственного поля «Сообщение» внутри клавиатуры нет. Для форматов контента Android действуют ограничения из ТЗ. При отсутствии исходного скриншота генератор рисует условную миниатюру; это не модель копирования изображения.

Группы для обзора: `A_...`, `B_...`, `C_...`, `D_...`, `E_...`. При утверждении смотреть отдельные PNG в масштабе 100%.
