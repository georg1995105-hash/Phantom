Emoji search keywords are frozen local copies of Unicode CLDR Russian and English annotations, fetched 2026-11-05 from:
https://github.com/unicode-org/cldr-json/tree/main/cldr-json/cldr-annotations-full/annotations

The application searches only emoji present in its supported keyboard, using these annotations plus Unicode character names. No query is sent to a server. License: app/src/main/assets/emoji_search_LICENSE.txt (Unicode License v3).
