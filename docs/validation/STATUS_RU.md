# Проверка preview · 5 ноября 2026

Тестовая ветка `redesign/reference-preview-20261105` основана на актуальной `redesign/v02-foundation` (46cc6f8). PR #6 не сливался. Стабильная ветка и установленная стабильная клавиатура не заменяются: preview имеет applicationId `ru.smartvoice.keyboard.preview`, название **SmartVoice Test** и собственные provider authorities.

## Что изменено

Реализованы графитовая тема, цифровой ряд и верхняя панель; сетка функций 3×3 с редактором и сохранением порядка; категории/поиск/недавние эмодзи; двухколоночный буфер с фильтрами, поиском, настоящими изображениями, ссылками, закреплением и выбором. Старые пользовательские настройки больше не перезаписываются миграцией. Для изображений предусмотрены проверка доступности, системная попытка вставки и явное действие «Поделиться», если принимающее поле не поддерживает изображение.

Голосовой контроллер защищён от запоздалых ответов старого сеанса и повторных final; сохраняет последний partial при пустом final; ограничивает повторные попытки и время ожидания. «Готово» ожидает заключительный результат с ограниченным сроком. Выбор гипотез использует только согласованные confidence scores. Ссылки/email защищены при постобработке. Офлайн-режим не переключается незаметно на сетевой движок.

## Выполненные проверки

- Preview APK собрана `assembleDebugNoMinify -PsmartvoicePreview=true`; установлена и запущена на Android 10 / API 29, 720×1280, 320 dpi. Проверены активация IME, русский посимвольный ввод, открытие основных панелей, возврат, настоящий системный clipboard с текстом, URL и изображением. Изображение в буфере — снимок самой клавиатуры, а не нарисованная фотография.
- Снимки `screenshots/` получены из работающей APK. Все четыре опубликованных экрана получены через Android `screencap`. В ходе разработки также применялась отрисовка измеренного Android View для диагностики панелей. Это не новые макеты. Сравнение с оригиналами: `COMPARE.html`. Файлы 02/04 в исходном архиве перепутаны; сопоставление сделано по содержимому.
- Полный прогон unit-тестов: **215, прошли 204, упали 11**. На неизменённой исходной ветке: **198, прошли 181, упали 17**. Все 17 добавленных проверок прошли; все текущие падения присутствовали в исходной базе. Перечень — `remaining-tests.txt`. Набор нельзя считать полностью зелёным.
- Первоначальная диагностика Android lint выявила 262 ошибки (247 MissingTranslation, 15 NewApi) и 151 предупреждение в проекте. Часть затронутых NewApi устранена; полный lint после последних исправлений не повторялся. Чистый lint не заявляется.
- Исправлены выявленные запуском ошибки: получение названия preview-приложения с literal label, выбор контрастного текста акцентных элементов, расчёт высоты панелей эмодзи, обработка недоступных миниатюр, скрывавшая стрелку возврата унаследованная прокрутка заголовка буфера вправо. CI дополнен резервированием диска эмулятора; успешный CI этим отчётом не подтверждается.

## Проверки, которые остаются на телефоне

Программный эмулятор без аппаратного ускорения не измеряет плавность. API 31–36, разные размеры/ориентации, drag-and-drop, все принимающие приложения и реальная русская диктовка требуют проверки на устройстве. Эмулятор API 35 в этой среде завершался до установки приложения; это ограничение среды, а не результат проверки APK.

В текущем эмуляторе при русском вводе строка кандидатов не дала слов (enabled=true, count=0); существующий механизм подсказок сохранён, но три рабочих русских кандидата этим запуском не подтверждены. Требуется отдельно проверить наличие словаря и подсказки на телефоне. Удалён дополнительный auto-correction span; стандартное подчёркивание composing-текста принимающим Android-полем может оставаться.

Реальный звук не записывался. **WER/CER и задержка не измерены**, улучшение точности в процентах не заявляется. В `tools/voice-evaluation/` есть 30 фраз, CSV и скрипт сравнения до/после. Порядок проверки: `PHONE_TEST_RU.md`.

Сборка предназначена для тестирования. Стабильный выпуск и слияние в main возможны только после проверки владельцем и его явного одобрения.
