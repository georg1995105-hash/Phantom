# Factory Droid — начать разработку SmartVoiceKeyboard

**Поручение владельца:** разработать личную настоящую Android-клавиатуру, а не очередной рисунок или демо.

Рабочий каталог: `/home/factory-droid/projects/SmartVoiceKeyboard`. Перед правками `git status`, затем `git pull --ff-only` из main при чистом дереве.

**Единственный приоритетный источник требований:** [IMPLEMENTATION_SPEC_v2.md](IMPLEMENTATION_SPEC_v2.md). Старые макеты/спеки с ошибками не считать авторитетными.

Сначала выбери законную, собираемую основу среди HeliBoard/FUTO (или докажи необходимость другой), затем сразу реализуй рабочую InputMethodService-клавиатуру и **собери настоящий APK**. Не останавливайся после исследования и плана. Обычная клавиатура должна реально печатать в сторонних приложениях; не рисуй отдельное поле ввода. Не убирай русскую раскладку/цифры/предсказания ради мини-дизайна.

Затем доводи настройки и поведение к Gboard: 4 точки слева, подсказки и микрофон, компактное последнее копирование, двухколоночный буфер, настоящий жестовый набор RU/EN, локальное персонализированное автодополнение, голосовой ввод прямо в поле, темная/светлая темы. Обязательный UI resize: поверх затемненной клавиатуры ПО ЦЕНТРУ `Сброс`, перемещение, `Готово` и рамка по краям; ни сверху, ни в отдельном экране. Стрелка «Назад» в меню функций и истории буфера.

Не маскируй неработающие функции красивыми кнопками. Учитывай ограничения Android и лицензий. До загрузки больших моделей проверь остаток диска/RAM. Не трогай иные проекты, сервисы, серверные ключи и конфигурации. **У Deploy Key только чтение, не пытайся делать push и не изменяй права.** Работай локальными коммитами.

Проверяй Gradle-сборку, установки/открытия IME в доступном окружении, тесты основных клавиш, режимов ввода, Backspace, подсказок, буфера. Не выдавай сборку за проверку на реальном устройстве. Результат: доступный debug APK, точный путь, SHA-256, версия/commit, инструкция установки и активации на Android, список реально проверенных функций и ограничений. Если весь объём нельзя качественно закончить за один цикл — отдай работоспособный APK, честно перечисли оставшиеся пункты и продолжай по согласованным этапам.
