Как начать

Установка занимает несколько действий. Удалять старую официальную версию перед обновлением не требуется.

01

Скачайте

Нажмите «Скачать APK» — ссылка автоматически ведёт на последнюю стабильную версию GitHub Releases.

02

Установите

Откройте APK на телефоне, планшете или Android TV. При необходимости разрешите установку через браузер.

03

Подключитесь

Добавьте ссылку подписки или отдельный ключ, выберите сервер и включите VPN.

Стабильные обновления

Основная кнопка ведёт на «latest», а не на номер версии: после официального выпуска нового стабильного релиза адрес скачивания остаётся прежним. Предварительные сборки не подменяют стабильные.

Важно: для обновления установленного приложения используйте только официально подписанные APK из GitHub Releases. Тестовые сборки Pull Request подписываются отдельно. Доступность GitHub зависит от сети: если загрузка не начинается, откройте ссылку в браузере с работающим подключением.
