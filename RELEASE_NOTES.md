# PHANTOM VPN 0.3.24

- Добавлен переключатель «Получать бета-обновления» в «Настройки → О приложении» на телефоне и Android TV. По умолчанию выключен; после смены канала обновления проверяются заново.
- Стабильный канал показывает только официальные стабильные версии. Бета-канал предлагает и стабильные выпуски, и нумерованные тестовые версии с тегом X.Y.Z-beta.N.
- Для всех каналов используется один универсальный APK, тот же официальный ключ подписи, тот же пакет и один механизм обновления поверх установленного приложения с сохранением данных.
- Возврат с бета-канала на стабильный не понижает Android versionCode: следующая стабильная версия предложится только когда она действительно новее установленной.
- Фоновые обновления и экран установки учитывают выбранный канал; нельзя установить ранее загруженную бету после отключения бета-режима. В окне обновления тестовая версия явно отмечена.
- Бета-версии выпускаются как GitHub Prerelease, которые не заменяют последнюю стабильную версию на app.veor.pro. Полные Android/TV-аудиты — по отдельному запросу, адресные проверки обязательны при критичных изменениях.

# PHANTOM VPN 0.3.23

- Исправлены тесные заголовки подписок на телефоне: название и кнопки отдельно, строка «Обновлено» ниже на всю доступную ширину, с однострочным сокращением только при нехватке места.
- Во всех карточках порядок действий одинаковый: обновить подписку, проверить пинг, открыть меню. Проверки и обновления по-прежнему выполняются независимо для каждого провайдера; меню и кнопки не дублируются.
- Отображаемое имя предпочитает название, заданное пользователем; без него сохраняется оригинальное имя провайдера. Особого оформления или переименования Phantom нет.
- Добавлены регрессионные тесты имён, различения одинаковых подписок и расположения кнопок.
- Протоколы, VPN-ядра, маршрутизация, подписки, TV/планшетные экраны и официальный ключ подписи не менялись.

# PHANTOM VPN 0.3.22

- У каждой подписки и одиночного ключа с поддерживаемым протоколом своя кнопка проверки пинга прямо в карточке. Проверяются все поддерживаемые серверы этой подписки; запуск повторно блокируется до окончания измерений.
- Из меню карточки удалён дублирующий пункт проверки пинга. Обновление подписки, копирование, QR, закрепление, отправка и удаление остались доступны.
- Карточки всех подписок получили единое компактное оформление: меньше пустых отступов, аккуратнее трафик и срок действия, прежние «Подробнее» и объявления сохранены.
- Android TV и планшеты: кнопки импорта и QR теперь заметно активные и окрашены в выбранную тему. В зелёной теме основная кнопка зелёная, QR — зелёная с рамкой; пульт и сенсор управляют теми же действиями.
- Для предотвращения регрессий добавлены тесты одинаковых действий пинга у двух независимых подписок и планшетных кнопок: цвет, доступность, нажатия, единая прокрутка.
- Один универсальный APK с официальной подписью Phantom; единое обновление для телефона, планшета и Android TV. При несовместимой подписи старой установки Android по-прежнему требует однократный перенос через резервную копию.
