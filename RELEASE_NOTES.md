# PHANTOM VPN 0.2.8

- Список подписок стал компактнее: убраны лишние отступы, время обновления указано рядом с названием.
- В выборе приложений теперь показываются их настоящие значки.
- Конфигурацию можно импортировать из файла и экспортировать для выбранного сервера.
- Меню добавления оформлено в цветах активной темы.
- Сообщения больше не сдвигают главный экран при проверке пинга и обновлении подписки.
- Обновления перенесены вниз; описание изменений отображается перед установкой.
- Добавлен экран протоколов, компонентов и лицензий.
- Нижняя область Android согласована с темой, без скрытия системной навигации.

Сохранены существующие подписки, настройки и подпись приложения. Серверы VPN не изменялись.
