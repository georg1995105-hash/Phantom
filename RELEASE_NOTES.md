# PHANTOM VPN 0.3.21

- Один Phantom для Android, планшета и Android TV. Отдельная Beta с другим идентификатором приложения исключена из сборки; отныне один официальный канал обновлений.
- Только один универсальный APK для ARM64, ARM32, x86 и x86_64. Отдельные файлы для процессоров больше не производятся и не публикуются.
- Все следующие официально подписанные обновления ставятся поверх предыдущих версий с сохранением подписок и настроек.
- Главная: текущая страна остаётся в верхней строке; повторная карточка Германии и лишний заголовок серверов убраны. Подписки начинаются непосредственно под состоянием подключения.
- Порядок на всех устройствах: сначала подписки со своими серверами, потом одиночные ключи, затем импорт и QR. Индивидуальные кнопки обновления, пинги, избранное, меню и подробности подписок сохранены.
- На телевизорах и планшетах серверы сразу на главной в две колонки, с более компактным управлением VPN и пультом. Время подключения показывается только внутри кнопки питания.
- TV: окно обновления компактное и не скрывает кнопки действия. Список изменений прокручивается внутри окна.
- Если ранее установленное приложение подписано другим ключом (например, временный CI APK), Android запрещает установку поверх. Это ограничение безопасности системы: один раз сохраните резервную копию, удалите старую копию и установите официальный Phantom, затем восстановите данные. После перехода обычные OTA будут работать на всех устройствах.
- Отдельный пакет `xyz.wraithnet.phantom.beta` тоже не может быть превращён в `xyz.wraithnet.phantom` обновлением поверх: это разные Android-приложения.
