# PHANTOM VPN 0.2.17

- Устранена преждевременная обязательная TUIC/AnyTLS HTTPS-проверка до создания Android VPN. Теперь удалённый трафик проверяется после запуска TUN и Xray, а локальный SOCKS5 — до него.
- Исправлена диагностика локального SOCKS5: фактическое согласование версии и метода, а не только открытие TCP.
- Для готовности TUIC/AnyTLS требуется три последовательных успешных SOCKS5-рукопожатия; ошибки подключения и обрывы сокета различаются.
- В отдельном процессе sing-box команды START/STOP связаны с идентификатором сеанса: запоздавшая остановка старого профиля не должна выключать новый.
- Устранено подтверждённое Android CI падение `RejectedExecutionException`: прекращена отправка STOP одновременно с unbind, а обработчик игнорирует опоздавшие Binder-команды после `onDestroy`. Проверка воспроизводит быстрые переключения.
- Фоновый процесс sing-box получает повышенный приоритет, пока привязан к основному VPN-сервису, чтобы снизить риск остановки Android.
- Добавлен запрос состояния дочернего процесса при отказе HTTPS, без раскрытия ключей.
- Android-тест проверяет многократные реальные SOCKS5-рукопожатия и повторное подключение, не требуя удалённого сервера.
- Не изменены production-серверы, main и конфигурации Xray. Это экспериментальная версия; удалённый TUIC ещё не проверен на реальном телефоне.

## Изменения предыдущей версии

# PHANTOM VPN 0.2.16

Экспериментальная сборка для проверки TUIC/AnyTLS на Android.

- Удалена лишняя надпись «Phantom VPN» с верхней панели.
- Исправлен сетевой адаптер libbox: фактические интерфейсы, DNS физической сети, мониторинг Wi-Fi/мобильной сети вместо пустого списка и фиктивного обработчика.
- Включено `route.auto_detect_interface` для защиты исходящих сокетов TUIC/AnyTLS от попадания обратно в VPN.
- Проверка HTTPS через SOCKS5 теперь сообщает безопасный этап сбоя без паролей и адресов серверов; принимает успешный HTTP 2xx/3xx, исключая ложные ошибки из-за отсутствия ответа 204.
- Протоколы основной подписки Xray и её ключи не изменены.
- CI подтверждает только сборку, изоляцию Go и локальные тесты; реальная работа TUIC требует отдельного испытания на телефоне.

## Предыдущее обновление 0.2.15


- Исправлена схема SOCKS5 outbound Xray для транспорта TUIC/AnyTLS: актуальные `address` и `port`, без устаревшего `servers`. Это устраняет выявленную ошибку маршрутизации между движками.
- Все одиночные ключи собраны в одну секцию «Отдельные ключи». У каждого одно меню «⋮»; обновление URL для ключей не показывается.
- В подписке одно меню в шапке с действием «Копировать подписку», без лишних меню у серверов внутри.
- Внизу доступны действия «Вставить» (сразу из буфера) и «Добавить», верхний «+» убран.
- Исправлены выбор TUIC/AnyTLS рядом с обычными серверами, закрепление, задержка после проверки через подключённый туннель.
- Продакшн-ветка и серверы не изменены; сетевое подключение проверяется отдельно от запуска нативных библиотек.



- Исправлен ручной выбор TUIC и AnyTLS при одновременном наличии основной подписки Xray/Hysteria2, без отключения других подписок.
- Выбор сервера сохраняет привязку к своей подписке, даже если в разных подписках совпали идентификаторы ключей.
- Реальная задержка TUIC/Hysteria2 показывается после успешного подключения и HTTPS-проверки через туннель, без ложного TCP-пинга для UDP.
- Для одиночной ссылки убран неуместный селектор; у закреплённой подписки появился видимый значок и подтверждение.
- Проверяется последовательный запуск изолированного Go-процесса и повторное подключение; production остаётся без изменений.

- Новый экспериментальный движок sing-box 1.14.4 для TUIC v5 и AnyTLS. Он запускается локально и передаёт TCP/UDP через SOCKS5 в существующий VPN-туннель Xray.
- Прямые ссылки `tuic://` и `anytls://`, в том числе внутри смешанных подписок, теперь распознаются и сохраняются.
- Для TUIC включена проверка TLS-сертификата по умолчанию, используются UUID, пароль, SNI и ALPN из ссылки.
- Xray продолжает обслуживать VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и XHTTP/REALITY. Переписывания подписок и серверов нет.
- Два независимых Go-движка изолируются при сборке, чтобы не конфликтовали Android-классы и нативные библиотеки.
- Добавлены тесты импорта, генерации конфигураций и маршрутизации TCP/UDP.

Важное: стабильность переключений движков и фактический трафик TUIC на Android требуют отдельной проверки на телефоне. Наличие ссылок в списке и успешный CI не подтверждают реальную работу. Поддержка всех будущих VPN-протоколов не может быть гарантирована.
