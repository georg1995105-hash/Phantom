# SmartVoiceKeyboard

Текущая переработка выполняется по **[утверждённому заданию от 05.11.2026](docs/approved-design/TASK_FOR_CODEX.md)** и четырём PNG. [Карта файлов](docs/approved-design/README.md) поясняет перепутанные названия двух изображений в исходном архиве.

Тестовая сборка: `ru.smartvoice.keyboard.preview`, название **SmartVoice Test**. Устанавливается отдельно, включая отдельные ContentProvider. Стабильный выпуск и слияние в `main` требуют проверки и одобрения владельца.

[Телефонный протокол](docs/validation/PHONE_TEST_RU.md) содержит ручные сценарии и 30 фраз для сравнения диктовки. [Сравнение экранов](docs/validation/COMPARE.html) использует утверждённые PNG и реальные снимки Android UI.

Документы `docs/IMPLEMENTATION_SPEC_v2.md`, `docs/UI_DESIGN_SPEC_v1.md`, `docs/DRAFT_REQUIREMENTS.md` и старые `docs/mockups` сохранены как история; при расхождениях действует утверждённое задание.

Цель: настоящая нативная Android IME с русской/английской раскладкой, вводом жестами, мгновенными локальными подсказками, голосом, умным буфером (миниатюры фото/скриншотов), простой настройкой, размерами как в Gboard и уважением к приватности. **Никаких собственных полей сообщений внутри клавиатуры.**

Локальный каталог Droid на CONTROL: `/home/factory-droid/projects/SmartVoiceKeyboard`. GitHub Deploy Key подключён на чтение: это позволяет `pull`, но **не позволяет `push`**; агенту нельзя самостоятельно менять ключи/права.

Сначала нужно получить устанавливаемый реально работающий debug APK и проверить его, а не останавливаться на дизайне или плане. Дальнейшие функции реализуются итеративно по v2.
