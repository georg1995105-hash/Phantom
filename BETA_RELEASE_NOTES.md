# Phantom Beta — канал предварительных обновлений

- Отдельное приложение Phantom Beta: устанавливается рядом с обычным Phantom и не заменяет его.
- Независимый канал бета-обновлений: тестовые версии не отправляются пользователям Stable.
- Независимые подписки и сохранение серверов при ошибках обновления.
- Компактная проверка задержки: независимый TCP-вход или реальная проверка через профиль.
- Универсальная сборка для ARM32, ARM64, x86 и x86_64, включая Android TV.
- Проверка подписи и SHA-256 перед установкой. Android может запросить подтверждение.
